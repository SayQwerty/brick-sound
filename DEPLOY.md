# Автодеплой Brick Sound

Сайт Netlify: https://brick-sound.netlify.app
Репозиторий: https://github.com/SayQwerty/brick-sound

## Включить обновление с каждого пуша

1. Залейте папку сайта (все HTML, css, js, img) в этот репозиторий: Add file → Upload files.
2. Откройте https://app.netlify.com/projects/brick-sound
3. Project configuration → Build & deploy → Continuous deployment → Link repository → GitHub → SayQwerty/brick-sound
4. Publish directory: .

Дальше любой коммит в main сам обновляет сайт.
